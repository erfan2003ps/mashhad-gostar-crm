# سامانه CRM مشهد گستر

نسخه وب فروش، باشگاه مشتریان و میز کار. برای استفاده واقعی این را با Node اجرا کنید تا داده پشت ورود بماند:

```bash
npm start
```

پیش‌فرض روی پورت `3000` است. فایل `index-3.html` را سرور خودش می‌دهد.

- مسیر `/api/state` بدون نشست ورود نه خوانده می‌شود و نه عوض می‌شود.
- رمز کاربران با scrypt ذخیره می‌شود و در پاسخ سرور برنمی‌گردد.
- پایگاه روی دیسک با AES-256-GCM رمز می‌شود. کلید را با متغیر `MG_DATA_KEY` تنظیم کنید.
- کارشناس بدون مجوز حذف نمی‌تواند مشتری، استعلام یا معامله را پاک کند. لغو و بایگانی معامله ثبت می‌ماند.
- ورود اولیه مدیر `admin` و رمز `123456` است. تا وقتی رمز قوی (حداقل ۱۰ کاراکتر، حرف و عدد) گذاشته نشود، داده سرور باز نمی‌شود.

متغیرهای محیط: `PORT`، `MG_HOST`، `MG_DATA_DIR`، `MG_DATA_KEY`، `MG_ADMIN_PASSWORD`.
